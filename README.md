# Trexon General Contracting — Website

Static website for Trexon General Contracting Establishment (Dammam, KSA).

## Pages
- index.html — Home
- services.html — Our Services (+ 5 service detail pages)
- about.html — About Us
- contact.html — Contact Us

## Deploy with GitHub Pages
1. Push these files to the repository root.
2. Repo Settings → Pages → Source: Deploy from a branch → main, / (root).
3. Live at https://flawlesspixelz-creator.github.io/trexon/
